# あにまるカフェ Oasis｜WordPress テーマ 導入手順

静的サイト（HTMLファイル）を、WordPress で更新できるようにしたものです。
**写真も文章も、すべて管理画面から差し替えられます。**

---

## 1. テーマを入れる

1. WordPress の管理画面 →「**外観**」→「**テーマ**」
2. 上の「**新規追加**」→「**テーマのアップロード**」
3. `animal-cafe-oasis.zip` を選んで「**今すぐインストール**」
4. インストールが終わったら「**有効化**」

> **「アップロードしたファイルはサーバーの上限を超えています」と出たら**
> テーマの zip が約11MBあるためです。FTP で `wp-content/themes/` に
> `animal-cafe-oasis` フォルダごと置いても同じように使えます。

---

## 2. 初期データを取り込む（これが一番大事です）

1. 管理画面 →「**設定**」→「**Oasis サイト設定**」
2. 一番下の「**初期データを取り込む**」を押す

これだけで、次のものがまとめて登録されます。

- **どうぶつ 21種**（写真47枚＋店内POPカード21枚）
- 固定ページ 6枚（店舗紹介・メニュー・ご利用ルール・アクセス・生体販売・お知らせ）
- ヘッダー／スマホ／フッターのメニュー
- お知らせのサンプル記事 3件

「お迎えできる子」（生体販売の個体）は、お店ごとの内容なので初期データには含めていません。

> 写真の枚数が多いので、**1〜3分ほどかかります**。画面が切り替わるまでお待ちください。
> もう一度押しても、すでにあるものは飛ばすので増えません。

---

## 3. お店の情報を入れる

「**設定**」→「**Oasis サイト設定**」で、次を実際の値に変えてください。
ここを直すと、**サイト全体の表示がまとめて変わります**。

| 項目 | 使われる場所 |
|---|---|
| 電話番号（表示用・発信用） | ヘッダー・フッター・各ページのボタン |
| 住所 | フッター・アクセス |
| Instagram の URL | ヘッダー・スマホ下部のボタンなど（空だとボタンが出ません） |
| 営業時間・定休日・臨時休業日 | **「本日 営業中」の自動表示**にも使われます |
| Googleマップの埋め込みコード | トップとアクセスの地図 |
| 第一種動物取扱業の表記 | フッター |

---

## 4. どうぶつの写真を差し替える

「**どうぶつ**」→ 名前をクリック。

| 欄 | 内容 |
|---|---|
| **メイン写真**（右側の「アイキャッチ画像」） | 一覧のカード・個別ページの大きな写真・丸いリンクに使われます |
| **サブ写真** | 個別ページのサムネイルに並びます。押すとメイン写真が入れ替わります。**ドラッグで並べ替え**できます |
| **店内POPカード** | ページ下部に、切り抜かずそのまま載ります |

**写真は1枚アップロードすれば、必要な大きさに自動で切り抜かれます。**
切り抜きは中央が基準なので、被写体が中央にくる写真を選んでください。

> 一覧画面（「どうぶつ」の一覧）でも、どの子に写真が入っているか一目で分かります。

---

## 4-2. そのほかの写真を差し替える

**設定 → Oasis 写真の差し替え**

トップの大きな写真、店内、外観、スタッフ、来店の流れ、ドリンク、
第二駐車場の案内図など、**サイトの写真をこの1画面でまとめて入れ替えられます。**

- 写真は1枚アップロードすれば、必要な大きさに自動で切り抜かれます
- 選んでいない枠は、これまでどおり色のついた四角のままです
- どうぶつの写真だけは「どうぶつ」の編集画面、お知らせの写真は記事の
  「アイキャッチ画像」です

## 5. 「お迎えのご相談」を出す／出さない

個別ページの下のほうに出る、電話・Instagram のご案内の枠です。

**1件ずつ切り替える**
「どうぶつ」→ 名前をクリック → 右側の「**お迎えのご相談**」のチェックを外す。

**まとめて切り替える**
「どうぶつ」の一覧で、対象にチェックを入れる →
上の「**一括操作**」から「お迎えのご相談を『出さない』にする」→「適用」。

**サイト全体でまとめて消す**
「設定」→「Oasis サイト設定」→「表示の切り替え」→
「**お迎えのご相談を使う**」のチェックを外す。

一覧画面の「お迎え」の列で、いまどうなっているか確認できます。

---

## 6. どうぶつを追加する

「**どうぶつ**」→「**新規追加**」

1. タイトルに名前（例：ミーアキャット）
2. 右側の「**カテゴリ**」を選ぶ（一覧の絞り込みに使われます）
3. 右側の「**アイキャッチ画像**」にメイン写真
4. 「写真」の欄でサブ写真とPOPカードを選ぶ
5. 「どうぶつのデータ」に、店内POPカードの内容を入れる
6. 「公開」

**並び順**は、右側の「**順序**」の数字が小さいものから並びます。

---

## 7. お迎えできる子（生体販売）を載せる

「**お迎えできる子**」→「**新規追加**」

生体販売ページに並ぶ、1匹ずつのカードです。
「どうぶつ」が種類の説明なのに対して、こちらは**いまお迎えできる個体**の登録です。

1. タイトルに名前（例：ネザーランドドワーフ／うさこ）
2. 右側の「**写真**」でその子の写真を選ぶ
3. 「この子のデータ」に入力する
   - **種類**：どうぶつから選ぶと、カードがその子の紹介ページへのリンクになります
   - **性別**：オス／メス／不明（「選ばない」なら行ごと出ません）
   - **金額**：「88,000円」「応相談」など自由入力（空なら行ごと出ません）
   - **ひとこと**：カードの下に小さく出ます（任意）
4. 「公開」

右側の「**お知らせにも載せる**」にチェックが入っていると、公開したときに
**お知らせ（カテゴリ：入荷）に記事が1本できます**（写真・名前・性別・金額から自動で作成）。
できた記事はあとから自由に書き換えられます。作られるのは1回だけです。
載せたくないときは、公開する前にチェックを外してください。

**並び順**は右側の「**順序**」の数字が小さい順。
お迎え先が決まったらゴミ箱へ移動するか、下書きに戻すとページから消えます。
1匹も登録が無いときは「ご案内は準備中です」という文が出ます。

> 写真を入れなくても、「種類」を選んでいればその子の写真が自動で使われます。

---

## 8. お知らせを書く

「**投稿**」→「**新規追加**」。カテゴリ（入荷／休業／店内の様子）を選ぶと、
お知らせページの絞り込みがそのまま効きます。
アイキャッチ画像がカードの写真になります。

## よくある質問

**Q. 写真を差し替えたのに、切り抜きが古いままです**
プラグイン「Regenerate Thumbnails」で作り直してください。

**Q. ページの見た目が崩れました**
固定ページの本文は「HTML」ブロックとして入っています。
ブロックを分解するとデザインが崩れるので、**ブロックの中の文字だけ**直してください。

**Q. メニューを変えたい／英字を変えたい**
「外観」→「メニュー」。項目を開くと、次の2つが入力できます。

| 欄 | 入れるもの |
|---|---|
| ナビゲーションラベル | **日本語**（ホーム、生体販売 など） |
| **英字** | **HOME、SALES など**（PCヘッダーの上段／スマホメニューの右に出ます） |

**英字を空にすると、リンク先から自動で入ります**
（HOME／OASIS／ANIMALS／PRICE／RULES／SALES／ACCESS／NEWS）。
好きな英字にしたいときは、この欄に直接書いてください（SHOP、GALLERY など自由）。

ヘッダー・スマホ・フッターは別々のメニューなので、それぞれで設定できます。

**Q. 元の静的サイトはどこですか**
同じ zip の中の、`wordpress` フォルダの外側にすべて残してあります。
そのままブラウザで開けますし、GitHub Pages での公開もこれまでどおりです。

---

## うまくいかないときは

### 「このテーマはすでにインストールされています」と出る／別のテーマが入っている

`wp-content/themes/` に、**同じフォルダ名の別のテーマ**が入っています。
よくあるのが Extend Themes の「Oasis」（colibri-wp の子テーマ）で、
名前がかぶると「親テーマが見つかりません」というエラーになります。

このテーマのフォルダ名は `animal-cafe-oasis` なので、通常はかぶりません。
それでも出る場合は、`wp-content/themes/` の中を確認して、
使っていない同名のテーマを削除してください
（使用中のテーマは削除できないので、先に別のテーマを有効化してください）。

### 「親テーマが見つかりません。○○ 親テーマをインストールしてください」と出る

データベースに前のテーマの名前が「親テーマ」として残っている状態です。
この状態だと WordPress がテーマを読み込んでくれないので、
テーマ側では直せません。次のファイルで外から直します。

1. `wordpress/tools/oasis-fix-parent-theme.php` を用意する
2. `wp-content/mu-plugins/` フォルダに置く
   （`mu-plugins` フォルダが無ければ、その名前で新しく作ってください）
3. サイトか管理画面を**1回開く**
4. 直ったら、置いたファイルは**削除して構いません**

これで「使用中のテーマ」と「親テーマ」の記録がそろい、
前のテーマが無くてもこのテーマだけで動くようになります。

> 本物の子テーマを使っている場合は、このファイルは何もしません。

**Local の Adminer で直すこともできます**（同じことをします）
Local の「Database」→「Adminer」→ `wp_options` テーブル →
`option_name` が `template` の行 → `option_value` を `animal-cafe-oasis` に変更 → Save

### 「致命的なエラー」で colibri-wp などの前のテーマ名が出る

以前のテーマの情報がデータベースに残っていて、WordPress がこのテーマを
「前のテーマの子テーマ」と勘違いし、**前のテーマのプログラムまで一緒に
読み込んでしまっている**状態です。

**バージョン 1.0.3 以降では、テーマを読み込んだ時点で自動的に直します。**
それでも表示されない場合は、**ページを一度リロード**してください
（直した設定は次の表示から効きます）。

それでもだめなときは、前のテーマのフォルダの名前を変えてください。

1. Local のアプリで「**Go to site folder**」
2. `app/public/wp-content/themes/` を開く
3. `colibri-wp` フォルダの名前を `colibri-wp-old` などに変える
4. ブラウザを再読み込み

これで前のテーマが読み込まれなくなり、設定も自動でそろいます。
問題がなければ、あとでそのフォルダは削除して構いません。

### 「require_once ... が開けませんでした」と出る

以前のテーマの情報がデータベースに残っていて、WordPress がこのテーマを
「前のテーマの子テーマ」と勘違いしている状態です。

**バージョン 1.0.1 以降では自動で直る**ようにしてあります。
古い版を入れている場合は、テーマフォルダを新しいものに入れ替えてください。

Local をお使いの場合：
1. Local のアプリで「**Go to site folder**」
2. `app/public/wp-content/themes/` を開く
3. 中の `animal-cafe-oasis` フォルダを削除し、新しい `animal-cafe-oasis` フォルダを置く
4. ブラウザを再読み込み

### 画面が真っ白になった

テーマフォルダの中身が足りない可能性があります。
`animal-cafe-oasis` フォルダの中に `functions.php` と `inc` フォルダがあるか確認してください。

### zip のアップロードでエラーになる

zipが約11MBあるため、サーバーの上限を超えることがあります。
zipを展開して、`animal-cafe-oasis` フォルダごと `wp-content/themes/` に置いても同じように使えます。
