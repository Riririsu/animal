# 本番サーバーに公開するまでの手順

Local（お手元のパソコン）で確認したものを、レンタルサーバーで公開するまでの手順です。
**上から順にそのままやれば終わります。** 所要時間はだいたい2〜3時間です。

> **方針について**
> Local のサイトをまるごと引っ越すのではなく、**サーバーで新しく WordPress を入れて、
> テーマの「初期データを取り込む」で中身を入れ直す**やり方をおすすめします。
> このテーマは写真も文章も自動で入るので、引っ越しツールを使うより速くて確実です。
> Local で書いたお知らせなどがある場合だけ、あとから手で入れ直してください。

---

## 第1章　サーバーとドメインの準備

### 1-1. レンタルサーバーを契約する

WordPressが動くサーバーなら何でも構いません。国内でよく使われるのは次のあたりです。

| サーバー | 月額のめやす | 備考 |
|---|---|---|
| エックスサーバー | 約1,100円〜 | 速い・情報が多い |
| ロリポップ！（ハイスピード） | 約550円〜 | 安い |
| さくらのレンタルサーバ（スタンダード） | 約440円〜 | 老舗 |
| ConoHa WING | 約940円〜 | 管理画面が分かりやすい |

**選ぶときの条件**（今回のテーマを動かすのに必要です）

- PHP **7.4以上**（できれば8.1以上）
- 無料SSL（https）が使える
- アップロード上限が **20MB以上**（テーマのzipが約11MBあるため）

### 1-2. ドメインを決める

`animal-cafe-oasis.com` のような、お店の住所にあたる文字列です。
サーバー契約時に「ドメイン永久無料」が付いてくることが多いので、そこで取るのが楽です。

取ったあと、サーバーの管理画面で「**ドメイン設定**」に追加します。

### 1-3. SSL（https）を有効にする

サーバーの管理画面で「**無料独自SSL**」「**SSL設定**」といった項目を探して、
取ったドメインに対して有効にしてください。**反映まで数十分かかることがあります。**

> 有効になると、ブラウザのアドレス欄に鍵マークが出ます。
> ここを飛ばすと「保護されていない通信」と表示され、お客様に不安を与えます。

## 第2章　WordPressを入れる

### 2-1. インストール

サーバーの管理画面にある「**WordPress簡単インストール**」を使います。

入力するもの：

| 項目 | 入れるもの |
|---|---|
| サイトURL | 取ったドメイン（**https:// で始まるもの**を選ぶ） |
| サイトのタイトル | `あにまるカフェ Oasis` |
| ユーザー名 | `admin` は避けてください（狙われやすいため） |
| パスワード | 英大文字・小文字・数字・記号を混ぜて12文字以上 |
| メールアドレス | 普段見るもの |

**ユーザー名とパスワードは必ず控えておいてください。**

### 2-2. 管理画面に入る

`https://（あなたのドメイン）/wp-admin/` を開いてログインします。

## 第3章　最初の設定（テーマを入れる前にやります）

### 3-1. 設定 → 一般

| 項目 | 設定 |
|---|---|
| サイトのタイトル | `あにまるカフェ Oasis` |
| キャッチフレーズ | `鹿児島県霧島市国分のふれあい動物カフェ` |
| **サイト言語** | **日本語** |
| **タイムゾーン** | **東京** |
| 日付形式 | `2026年8月19日` |

最後に「**変更を保存**」。

### 3-2. 設定 → 表示設定

「**検索エンジンでの表示**」の
「検索エンジンがサイトをインデックスしないようにする」の
**チェックが外れていることを確認**してください。

> ここにチェックが入っていると、**Googleに一切載りません。**
> 公開準備中はチェックを入れ、公開時に外す、という使い方もできます。

### 3-3. 設定 → パーマリンク

「**投稿名**」を選んで「**変更を保存**」。

> これをやらないと、ページのURLが `?p=123` のような形になります。
> どうぶつ紹介ページのURLにも関わるので、**必ず先にやってください。**

### 3-4. 設定 → ディスカッション

店舗サイトなのでコメントは不要です。

- 「新しい投稿へのコメントを許可」の**チェックを外す**

### 3-5. いらないものを消す

**プラグイン → インストール済みプラグイン**
- `Hello Dolly` を削除
- `Akismet` は使わないなら削除（コメントを使わないので不要です）
- サーバー会社が勝手に入れたプラグインがあれば、内容を確認して不要なら削除

**投稿・固定ページ**
- サンプル投稿「Hello world!」を削除
- サンプル固定ページ「サンプルページ」「プライバシーポリシー」を削除
  （プライバシーポリシーは後で作り直しても構いません）

## 第4章　テーマを入れる

### 4-1. アップロード

**外観 → テーマ → 新規追加 → テーマのアップロード**

`animal-cafe-oasis.zip` を選んで「**今すぐインストール**」→「**有効化**」

> **「アップロードしたファイルは上限を超えています」と出たら**
> zipが約11MBあるためです。次のどちらかで解決します。
> - サーバーの管理画面で PHP の `upload_max_filesize` を 32M 以上にする
> - zipを展開して、`animal-cafe-oasis` フォルダごと FTP で
>   `wp-content/themes/` に置く

### 4-2. いらないテーマを消す

**外観 → テーマ** で、次の2つ以外は削除してください。

- あにまるカフェ Oasis（使用中）
- 標準テーマ **1つだけ**（`Twenty Twenty-Five` など）

> 標準テーマを1つ残すのは**保険**です。
> 何かあったとき、WordPressが自動でそちらに切り替えて画面を保ってくれます。

> **注意：`Oasis`（作者 Extend Themes）というテーマが入っていたら削除してください。**
> 別物です。名前が似ているだけの、まったく関係ないテーマです。

## 第5章　中身を入れる

### 5-1. 初期データの取り込み

**設定 → Oasis サイト設定** → 一番下の「**初期データを取り込む**」

これで次が一度に入ります。

- どうぶつ **21種**（写真47枚＋店内POPカード21枚）
- 固定ページ 6枚（店舗紹介・メニュー・ご利用ルール・アクセス・生体販売・お知らせ）
- ヘッダー／スマホ／フッターのメニュー
- お知らせのサンプル記事 3件

**写真が多いので1〜3分かかります。** 画面が切り替わるまで待ってください。

> 途中で止まってしまう場合は、もう一度押してください。
> すでに入ったものは飛ばすので、二重に増えることはありません。

### 5-2. お店の情報を入れる

同じ「**設定 → Oasis サイト設定**」の画面で、次を実際の値にします。
**ここを直すとサイト全体に反映されます。**

| 項目 | 例 | 出てくる場所 |
|---|---|---|
| 電話番号（表示用） | `0995-XX-XXXX` | ヘッダー・フッター・各ページ |
| 電話番号（発信用） | `0995XXXXXX` | 電話ボタンを押したときにかかる番号 |
| 住所 | `鹿児島県霧島市国分〇〇町1-2-3` | フッター・アクセス |
| Instagram の URL | `https://www.instagram.com/xxxx/` | 各所のボタン（空だとボタンが出ません） |
| 開店・閉店時刻 | `11:00` / `19:00` | **「本日 営業中」の自動表示**に連動 |
| 定休日 | 火 にチェック | 同上 |
| 臨時休業日 | `2026-08-20`（1行に1つ） | 同上 |
| 入場料の表記 | `1,000円（2ドリンク付）` | トップ・来店の流れ |
| 第一種動物取扱業 | 登録番号と期限 | フッター |

**「変更を保存」を忘れずに。**

### 5-3. Googleマップを入れる

1. Googleマップでお店を開く
2. 「**共有**」→「**地図を埋め込む**」→「**HTMLをコピー**」
3. 「設定 → Oasis サイト設定 →**Googleマップの埋め込みコード**」に貼り付け
4. 保存

トップページとアクセスページの地図が、まとめて入れ替わります。

### 5-4. サイトアイコン（ブラウザのタブに出る小さいアイコン）

**外観 → カスタマイズ → サイト基本情報 → サイトアイコンを選択**

512×512px 以上の正方形の画像（ロゴなど）を入れてください。

## 第6章　中身を仕上げる

### 6-1. まだ写真がない13か所

いただいた写真はすべて動物のものだったので、次はまだ色の四角のままです。

- トップ：来店の流れ3枚／ドリンク・ケーキ2枚
- 店舗紹介：店内の様子／外観／スタッフ3名
- メニュー：ドリンク・ケーキ
- 生体販売：説明の様子
- お知らせ：「臨時休業のお知らせ」のカード

写真が用意できたら、**設定 → Oasis 写真の差し替え** の画面で入れ替えます。
1画面にすべての枠が並んでいるので、そこから写真を選ぶだけです。

### 6-2. どうぶつの内容を確認する

**どうぶつ** の一覧を開いて、21種すべてを確認してください。

- 写真は合っているか
- 「**お迎えのご相談**」を出す子・出さない子（右側のチェックボックス）
  - ゾウガメなど、お迎えの取り扱いがない子はチェックを外す
  - まとめて変えたいときは、一覧でチェック → 上の「一括操作」から

### 6-3. 文章を確認する

**固定ページ**を1枚ずつ開いて、金額・営業内容・ルールが実際と合っているか確認してください。
特に次は仮の値が残っている可能性があります。

- メニューの価格
- ご利用ルールの文言
- 生体販売の説明

### 6-4. お知らせを1本書く

**投稿 → 新規追加**。サンプル記事3本は削除するか、内容を書き換えてください。
カテゴリ（入荷／休業／店内の様子）を選ぶと、絞り込みがそのまま効きます。
アイキャッチ画像がカードの写真になります。

## 第7章　公開前の確認

**スマホとパソコンの両方で**、次を1つずつ確認してください。

### 表示

- [ ] トップページが正しく出る（写真・営業時間・駐車場の案内）
- [ ] どうぶつ紹介で21種が並ぶ
- [ ] 絞り込み（爬虫類・鳥類・小動物・犬猫サル）が動く
- [ ] どうぶつの個別ページで、サムネイルを押すと写真が入れ替わる
- [ ] メニュー・ルール・アクセス・お知らせが表示される
- [ ] スマホでハンバーガーメニューが開く

### リンク・ボタン

- [ ] 電話ボタンを押すと、実際の番号に発信画面が出る
- [ ] Instagramボタンが正しいアカウントに飛ぶ
- [ ] Googleマップが表示され、押すと地図アプリが開く
- [ ] フッターのリンクがすべて正しいページに行く

### そのほか

- [ ] アドレス欄に**鍵マーク**が出ている（https）
- [ ] 「本日 営業中」の表示が実際の営業状況と合っている
- [ ] 存在しないURL（例：`/aaa`）を開くと、404ページが出る
- [ ] 設定 → 表示設定で、インデックスを妨げる設定になっていない

## 第8章　公開したあと

### 8-1. Googleに登録する

**Google Search Console**（無料）
1. `https://search.google.com/search-console` を開く
2. ドメインを登録（サーバーの管理画面でDNS認証するのが簡単です）
3. サイトマップとして `wp-sitemap.xml` を送信

> WordPressは 5.5 から `https://（ドメイン）/wp-sitemap.xml` を自動で作ります。
> プラグインは不要です。

**Googleビジネスプロフィール**
すでにお店を登録している場合は、ウェブサイトの欄に新しいURLを入れてください。
検索したときにサイトが出るようになります。

### 8-2. バックアップを設定する

サーバー会社の自動バックアップ機能をオンにしてください
（エックスサーバー・ConoHa などは標準で付いています）。

プラグインで取るなら `UpdraftPlus` が定番です。
**月に1回はバックアップが取れているか確認**してください。

### 8-3. 更新を続ける

| やること | 頻度 |
|---|---|
| WordPress本体の更新 | 通知が来たら（自動更新をオンにしておくと楽です） |
| お知らせの更新 | 月1回でも書いていると、検索に強くなります |
| 写真の追加・差し替え | 新しい仲間が来たとき |
| バックアップの確認 | 月1回 |

## 困ったときは

| 症状 | 対処 |
|---|---|
| 画面が真っ白になった | サーバーのファイルマネージャーで `wp-content/themes/` を開き、テーマフォルダの名前を変える → 標準テーマに戻ります |
| 「親テーマが見つかりません」 | 同じ名前の別テーマが入っています。`readme-oasis.md` の「うまくいかないときは」を参照 |
| 写真の切り抜きが古いまま | プラグイン `Regenerate Thumbnails` で作り直す |
| ページの見た目が崩れた | 固定ページの本文は「HTML」ブロックです。ブロックを分解せず、中の文字だけ直してください |
| 表示が遅い | サーバーのキャッシュ機能をオンにする |

## 参考：静的サイト版をサーバーに置く場合

WordPressを使わず、HTMLファイルのまま公開することもできます。

1. FTPソフト（FileZilla など）でサーバーに接続
2. 公開フォルダ（`public_html` や `www`）に、次をそのままアップロード
   - `*.html`（30ファイル）
   - `css` / `js` / `images` フォルダ
   - `robots.txt` / `sitemap.xml`
3. `https://（ドメイン）/` を開いて確認

**フォルダの構成は崩さないでください。** 崩すと表示が壊れます。

この方法は、更新のたびにHTMLを直接編集する必要があります。
お店の方が自分で更新するなら、WordPress版をおすすめします。
