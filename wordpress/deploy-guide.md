# 本番サーバーに公開するまでの手順

Local（お手元のパソコン）で確認したものを、レンタルサーバーで公開するまでの手順です。
**上から順にそのままやれば終わります。** 所要時間はだいたい3〜4時間です。

> **方針について**
> Local のサイトをまるごと引っ越すのではなく、**サーバーで新しく WordPress を入れて、
> テーマの「初期データを取り込む」で中身を入れ直す**やり方をおすすめします。
> このテーマは写真も文章も自動で入るので、引っ越しツールを使うより速くて確実です。
> Local で書いたお知らせなどがある場合だけ、あとから手で入れ直してください。

---

## 第1章　サーバーとドメインの準備

### 1-1. レンタルサーバーを契約する

WordPressが動くサーバーなら何でも構いません。国内でよく使われるのは次のあたりです。

| サーバー | 月額のめやす | 備考 |
|---|---|---|
| エックスサーバー | 約1,100円〜 | 速い・情報が多い |
| ロリポップ！（ハイスピード） | 約550円〜 | 安い |
| さくらのレンタルサーバ（スタンダード） | 約440円〜 | 老舗 |
| ConoHa WING | 約940円〜 | 管理画面が分かりやすい |

**選ぶときの条件**（今回のテーマを動かすのに必要です）

- PHP **7.4以上**（できれば8.1以上）
- 無料SSL（https）が使える
- アップロード上限が **20MB以上**（テーマのzipが約11MBあるため）

### 1-2. ドメインを決める

`animal-cafe-oasis.com` のような、お店の住所にあたる文字列です。
サーバー契約時に「ドメイン永久無料」が付いてくることが多いので、そこで取るのが楽です。

取ったあと、サーバーの管理画面で「**ドメイン設定**」に追加します。

### 1-3. SSL（https）を有効にする

サーバーの管理画面で「**無料独自SSL**」「**SSL設定**」といった項目を探して、
取ったドメインに対して有効にしてください。**反映まで数十分かかることがあります。**

> 有効になると、ブラウザのアドレス欄に鍵マークが出ます。
> ここを飛ばすと「保護されていない通信」と表示され、お客様に不安を与えます。

## 第2章　WordPressを入れる

### 2-1. インストール

サーバーの管理画面にある「**WordPress簡単インストール**」を使います。

入力するもの：

| 項目 | 入れるもの |
|---|---|
| サイトURL | 取ったドメイン（**https:// で始まるもの**を選ぶ） |
| サイトのタイトル | `あにまるカフェ Oasis` |
| ユーザー名 | `admin` は避けてください（狙われやすいため） |
| パスワード | 英大文字・小文字・数字・記号を混ぜて12文字以上 |
| メールアドレス | 普段見るもの |

**ユーザー名とパスワードは必ず控えておいてください。**

### 2-2. 管理画面に入る

`https://（あなたのドメイン）/wp-admin/` を開いてログインします。

## 第3章　最初の設定（テーマを入れる前にやります）

### 3-1. 設定 → 一般

| 項目 | 設定 |
|---|---|
| サイトのタイトル | `あにまるカフェ Oasis` |
| キャッチフレーズ | `鹿児島県霧島市国分のふれあい動物カフェ` |
| **サイト言語** | **日本語** |
| **タイムゾーン** | **東京** |
| 日付形式 | `2026年8月19日` |

最後に「**変更を保存**」。

### 3-2. 設定 → 表示設定

「**検索エンジンでの表示**」の
「検索エンジンがサイトをインデックスしないようにする」の
**チェックが外れていることを確認**してください。

> ここにチェックが入っていると、**Googleに一切載りません。**
> 公開準備中はチェックを入れ、公開時に外す、という使い方もできます。

### 3-3. 設定 → パーマリンク

「**投稿名**」を選んで「**変更を保存**」。

> これをやらないと、ページのURLが `?p=123` のような形になります。
> どうぶつ紹介ページのURLにも関わるので、**必ず先にやってください。**

### 3-4. 設定 → ディスカッション

店舗サイトなのでコメントは不要です。

- 「新しい投稿へのコメントを許可」の**チェックを外す**

### 3-5. いらないものを消す

**プラグイン → インストール済みプラグイン**
- `Hello Dolly` を削除
- `Akismet` は使わないなら削除（コメントを使わないので不要です）
- サーバー会社が勝手に入れたプラグインがあれば、内容を確認して不要なら削除

**投稿・固定ページ**
- サンプル投稿「Hello world!」を削除
- サンプル固定ページ「サンプルページ」「プライバシーポリシー」を削除
  （プライバシーポリシーは後で作り直しても構いません）

## 第4章　テーマを入れる

### 4-1. アップロード

**外観 → テーマ → 新規追加 → テーマのアップロード**

`animal-cafe-oasis.zip` を選んで「**今すぐインストール**」→「**有効化**」

> **「アップロードしたファイルは上限を超えています」と出たら**
> zipが約11MBあるためです。次のどちらかで解決します。
> - サーバーの管理画面で PHP の `upload_max_filesize` を 32M 以上にする
> - zipを展開して、`animal-cafe-oasis` フォルダごと FTP で
>   `wp-content/themes/` に置く

### 4-2. いらないテーマを消す

**外観 → テーマ** で、次の2つ以外は削除してください。

- あにまるカフェ Oasis（使用中）
- 標準テーマ **1つだけ**（`Twenty Twenty-Five` など）

> 標準テーマを1つ残すのは**保険**です。
> 何かあったとき、WordPressが自動でそちらに切り替えて画面を保ってくれます。

> **注意：`Oasis`（作者 Extend Themes）というテーマが入っていたら削除してください。**
> 別物です。名前が似ているだけの、まったく関係ないテーマです。

## 第5章　中身を入れる

### 5-1. 初期データの取り込み

**設定 → Oasis サイト設定** → 一番下の「**初期データを取り込む**」

これで次が一度に入ります。

- どうぶつ **21種**（写真47枚＋店内POPカード21枚）
- 固定ページ 6枚（店舗紹介・メニュー・ご利用ルール・アクセス・生体販売・お知らせ）
- ヘッダー／スマホ／フッターのメニュー
- お知らせのサンプル記事 3件

> 「**お迎えできる子**」（生体販売の個体）は、お店ごとの内容なので初期データには入りません。
> 第6章で登録します。

**写真が多いので1〜3分かかります。** 画面が切り替わるまで待ってください。

> 途中で止まってしまう場合は、もう一度押してください。
> すでに入ったものは飛ばすので、二重に増えることはありません。

### 5-2. お店の情報を入れる

同じ「**設定 → Oasis サイト設定**」の画面で、次を実際の値にします。
**ここを直すとサイト全体に反映されます。**

| 項目 | 例 | 出てくる場所 |
|---|---|---|
| 電話番号（表示用） | `0995-XX-XXXX` | ヘッダー・フッター・各ページ |
| 電話番号（発信用） | `0995XXXXXX` | 電話ボタンを押したときにかかる番号 |
| 住所 | `鹿児島県霧島市国分〇〇町1-2-3` | フッター・アクセス |
| Instagram の URL | `https://www.instagram.com/xxxx/` | 各所のボタン（空だとボタンが出ません） |
| 開店・閉店時刻 | `11:00` / `19:00` | **「本日 営業中」の自動表示**に連動 |
| 定休日 | 火 にチェック | 同上 |
| 臨時休業日 | `2026-08-20`（1行に1つ） | 同上 |
| 入場料の表記 | `1,000円（2ドリンク付）` | トップ・来店の流れ |
| 第一種動物取扱業 | 登録番号と期限 | フッター |

**「変更を保存」を忘れずに。**

### 5-3. Googleマップを入れる

1. Googleマップでお店を開く
2. 「**共有**」→「**地図を埋め込む**」→「**HTMLをコピー**」
3. 「設定 → Oasis サイト設定 →**Googleマップの埋め込みコード**」に貼り付け
4. 保存

トップページとアクセスページの地図が、まとめて入れ替わります。

### 5-4. URLを貼ったときの表示を決める

LINE・Instagram・X などにサイトのURLを貼ると、その下に
**見出し・説明文・画像**が出ます。ここを設定しておかないと、
そっけない表示になってしまいます。

**説明文**（Google の検索結果にも出ます）

設定 → Oasis サイト設定 → **サイトの紹介文**

初期値が入っているので、お店の言葉に直してください。
**80〜120文字くらい**がちょうどよく、長いと途中で切れます。

**画像**

設定 → Oasis 写真の差し替え → **URLを貼ったときに出る画像**

**横長（1200×630px くらい）**がきれいです。ロゴだけより、
お店の雰囲気が伝わる写真のほうが押してもらえます。
未設定のときはサイトアイコンが使われます。

> どうぶつやお知らせの個別ページを貼ったときは、**その子の写真と紹介文**が出ます。
> ここで設定するのは、トップページなどを貼ったときの表示です。

### 5-5. サイトアイコン（ブラウザのタブに出る小さいアイコン）

**外観 → カスタマイズ → サイト基本情報 → サイトアイコンを選択**

512×512px 以上の正方形の画像（ロゴなど）を入れてください。

## 第6章　中身を仕上げる

### 6-1. まだ写真がない10か所

いただいた写真はすべて動物のものだったので、次はまだ色の四角のままです。

- トップ：来店の流れ3枚（ご来店／受付／ふれあい）／ドリンク・ケーキ／Googleマップ
- 店舗紹介：店内の様子／外観
- メニュー：ドリンク・ケーキ
- アクセス：Googleマップ
- お知らせ：「臨時休業のお知らせ」のカード

写真そのものは**5種類**です（外観・店内・受付・ふれあい・ドリンク／ケーキ）。
トップとメニューのドリンク写真のように、同じ写真を2か所で使う分を含めて10か所です。
Googleマップは写真ではなく、5-3 で入れる埋め込みコードです。

写真が用意できたら、**設定 → Oasis 写真の差し替え** の画面で入れ替えます。
1画面にすべての枠が並んでいるので、そこから写真を選ぶだけです。

### 6-2. どうぶつの内容を確認する

**どうぶつ** の一覧を開いて、21種すべてを確認してください。

- 写真は合っているか
- 「**お迎えのご相談**」を出す子・出さない子（右側のチェックボックス）
  - ゾウガメなど、お迎えの取り扱いがない子はチェックを外す
  - まとめて変えたいときは、一覧でチェック → 上の「一括操作」から

### 6-3. 文章を確認する

**固定ページ**を1枚ずつ開いて、金額・営業内容・ルールが実際と合っているか確認してください。
特に次は仮の値が残っている可能性があります。

- メニューの価格
- ご利用ルールの文言

### 6-4. お知らせを1本書く

**投稿 → 新規追加**。サンプル記事3本は削除するか、内容を書き換えてください。
カテゴリ（入荷／休業／店内の様子）を選ぶと、絞り込みがそのまま効きます。
アイキャッチ画像がカードの写真になります。

### 6-5. お迎えできる子を登録する

**お迎えできる子 → 新規追加**（左メニューのハートのアイコン）

生体販売ページに並ぶ、**1匹ずつのカード**です。

1. タイトルに名前（例：ネザーランドドワーフ／うさこ）
2. 右側の「**写真**」でその子の写真を選ぶ
3. 「この子のデータ」に、**種類・性別・金額・ひとこと**を入れる
4. 「**公開**」

- 金額は自由入力です（`88,000円`／`応相談`／`お問い合わせください`）
- 性別や金額を空にすると、その行はカードに出ません
- 右側の「**お知らせにも載せる**」にチェックが入っていると、
  公開時に**お知らせ（入荷）に記事が1本できます**。不要なら外してください
- お迎え先が決まったら、ゴミ箱へ移動するか下書きに戻すとページから消えます
- 1匹も登録がないときは「ご案内は準備中です」と出るだけで、崩れません

### 6-6. メニューの並びと英字

**外観 → メニュー**。ヘッダー・スマホ・フッターの3つを別々に決められます。

項目を開くと「**英字**」の欄があります。
**空のままで構いません**（リンク先から自動で入ります）。
好きな英字にしたいときだけ、ここに書いてください。

## 第7章　セキュリティ

WordPress は世界で一番使われているぶん、**自動で穴を探して回るプログラムに毎日狙われます。**
狙われるのは「有名だから」ではなく「WordPress だから」です。
とはいえ、やることは決まっています。上から順にどうぞ。

### 7-1. プラグインを入れる前にやること（これが8割）

乗っ取りの原因は、ほとんどが**パスワード**と**更新の放置**です。
ここを固めないと、どんなプラグインを入れても意味がありません。

**① 管理者のユーザー名を `admin` 以外にする**

`admin` は真っ先に狙われる名前です。もしそうなっていたら：

1. **ユーザー → 新規追加** で、別の名前の管理者を作る
2. いったんログアウトして、新しいほうでログインし直す
3. **ユーザー** から `admin` を削除する
   （「すべての投稿を次のユーザーにする」で新しいユーザーを選んでください）

**② パスワードは自動生成のものをそのまま使う**

WordPress が出す長いパスワードをそのまま使い、**ほかのサービスと使い回さない**。
ブラウザかパスワード管理アプリに保存してください。紙のメモでも構いません。

**③ 自動更新をオンにする**

- **プラグイン** の一覧 → 各行の「**自動更新を有効化**」
- **外観 → テーマ** → 各テーマ → 「**自動更新を有効化**」
- WordPress 本体の小さな更新は、はじめから自動です

**④ 使わないプラグイン・テーマは「停止」ではなく「削除」する**

停止していても、ファイルが残っていると穴になることがあります。

**⑤ サーバーの自動バックアップをオンにする**（9-2 参照）

---

### 7-2. サーバー側の機能を先に使う（無料・プラグイン不要）

**多くのレンタルサーバーには、WordPress 用の防御機能が最初から付いています。**
プラグインより軽く、壊れにくいので、**まずこちらを使ってください。**

| サーバー | 場所 | オンにするもの |
|---|---|---|
| エックスサーバー | サーバーパネル → **WordPressセキュリティ設定** | 国外IPアクセス制限／ログイン試行回数制限／コメント・トラックバック制限 |
| ConoHa WING | サイト管理 → サイトセキュリティ | WordPressセキュリティ／WAF |
| ロリポップ！ | セキュリティ → **WAF設定** | 有効 |
| さくら | ドメイン/SSL → WAF設定 | 有効 |

**これだけでログイン攻撃のほとんどは止まります。**

> **注意：** WAF を有効にすると、まれに管理画面の保存が弾かれることがあります
> （長い文章や HTML を保存したときなど）。
> そのときはサーバー側の「WAF除外設定」で、その画面のURLだけ除外してください。

---

### 7-3. 入れるプラグインは、これ1つだけ

#### SiteGuard WP Plugin（作者：JP-Secure）

**プラグイン → 新規追加** で `SiteGuard` と検索 → インストール → 有効化。

**なぜこれか**

- **日本製・日本語**。設定画面が読めます
- **軽い**。サイトの表示が遅くなりません
- 国内のレンタルサーバーで実績が多く、情報も探しやすい

> ### ⚠ 有効化した直後に必ずやること
>
> **ログイン画面のURLが変わります。**
> 有効化すると画面の上に、新しいURL（例：`https://（ドメイン）/login_53791/`）が
> 一度だけ表示されます。
>
> **このURLを控えて、ブラウザにブックマークしてください。**
> 控え忘れると、自分もログインできなくなります。
> （同じ内容のメールも管理者アドレスに届きます。消さないでください）

**おすすめの設定**（有効化した時点でほぼこの状態になっています）

| 機能 | 設定 | 何をするか |
|---|---|---|
| 管理ページアクセス制限 | **ON** | ログインしていない人の管理画面アクセスを弾く |
| ログインページ変更 | **ON** | ログインURLを変える（← URLを控える） |
| 画像認証 | **ON** | ログイン画面に、ひらがなの入力を足す |
| ログイン詳細エラーメッセージの無効化 | **ON** | 「ユーザー名が違う」と教えない |
| ログインロック | **ON** | 何度も間違えた相手をしばらく締め出す |
| ログインアラート | **ON** | 誰かがログインするとメールが届く |
| XMLRPC防御 | **ON** | 古い仕組みを悪用した攻撃を止める |
| 更新通知 | **ON** | 更新が出たらメールで知らせる |
| **フェールワンス** | **OFF のまま** | 正しいパスワードでも1回目をわざと失敗させる機能。**混乱するので使わない** |
| WAFチューニングサポート | 触らない | 必要になったときだけ |

---

### 7-4. 入れなくていいもの・やってはいけない組み合わせ

| | 理由 |
|---|---|
| **セキュリティプラグインを2つ以上入れる** | **絶対にダメです。** ログイン制限どうしがぶつかって、**自分が入れなくなります** |
| Wordfence | 高機能ですが英語で、警告メールが毎日大量に届きます。個人店には重すぎます |
| All In One WP Security | SiteGuard と役割が同じです。どちらか一方に |
| Akismet | コメントを使わない設定なので不要です（3-5 で削除済み） |
| 「高速化」系プラグインの重ねがけ | サーバーのキャッシュ機能と競合して、表示が崩れることがあります |

> **プラグインは少ないほど安全です。** プラグイン自体が穴になることもあるので、
> 「便利そうだから」で増やさないでください。

---

### 7-5. 月に1回のチェック（5分）

- [ ] WordPress・テーマ・プラグインに更新が来ていないか
- [ ] バックアップが取れているか
- [ ] **ユーザー** に、見覚えのないユーザーが増えていないか
- [ ] サイトを開いて、身に覚えのない広告や外国語の文章が出ていないか
- [ ] ログインアラートのメールに、心当たりのないログインが無いか

### 7-6. もし乗っ取られたら

1. **あわてて消さない**（原因が分からなくなります）
2. サーバーの管理画面から、**サイトを一時的に非公開**にする
3. サーバー会社のサポートに連絡する（多くは復旧の相談に乗ってくれます）
4. バックアップから、**問題が起きる前の日**に戻す
5. すべてのパスワード（WordPress・サーバー・FTP）を変える

## 第8章　公開前の確認

**スマホとパソコンの両方で**、次を1つずつ確認してください。

### 表示

- [ ] トップページが正しく出る（写真・営業時間・駐車場の案内）

## 第9章　公開したあと

### 9-1. Googleに登録する

**Google Search Console**（無料）
1. `https://search.google.com/search-console` を開く
2. ドメインを登録（サーバーの管理画面でDNS認証するのが簡単です）
3. サイトマップとして `wp-sitemap.xml` を送信

> WordPressは 5.5 から `https://（ドメイン）/wp-sitemap.xml` を自動で作ります。
> プラグインは不要です。

**Googleビジネスプロフィール**
すでにお店を登録している場合は、ウェブサイトの欄に新しいURLを入れてください。
検索したときにサイトが出るようになります。

### 9-2. バックアップを設定する

サーバー会社の自動バックアップ機能をオンにしてください
（エックスサーバー・ConoHa などは標準で付いています）。

プラグインで取るなら `UpdraftPlus` が定番です。
**月に1回はバックアップが取れているか確認**してください。

### 9-3. 更新を続ける

| やること | 頻度 |
|---|---|
| WordPress本体の更新 | 通知が来たら（自動更新をオンにしておくと楽です） |
| お知らせの更新 | 月1回でも書いていると、検索に強くなります |
| 写真の追加・差し替え | 新しい仲間が来たとき |
| バックアップの確認 | 月1回 |

## 困ったときは

| 症状 | 対処 |
|---|---|
| 画面が真っ白になった | サーバーのファイルマネージャーで `wp-content/themes/` を開き、テーマフォルダの名前を変える → 標準テーマに戻ります |
| 「親テーマが見つかりません」 | 同じ名前の別テーマが入っています。`readme-oasis.md` の「うまくいかないときは」を参照 |
| 写真の切り抜きが古いまま | プラグイン `Regenerate Thumbnails` で作り直す |
| ページの見た目が崩れた | 固定ページの本文は「HTML」ブロックです。ブロックを分解せず、中の文字だけ直してください |
| 表示が遅い | サーバーのキャッシュ機能をオンにする |

## 参考：静的サイト版をサーバーに置く場合

WordPressを使わず、HTMLファイルのまま公開することもできます。

1. FTPソフト（FileZilla など）でサーバーに接続
2. 公開フォルダ（`public_html` や `www`）に、次をそのままアップロード
   - `*.html`（29ファイル）
   - `css` / `js` / `images` フォルダ
   - `robots.txt` / `sitemap.xml`
3. `https://（ドメイン）/` を開いて確認

**フォルダの構成は崩さないでください。** 崩すと表示が壊れます。

この方法は、更新のたびにHTMLを直接編集する必要があります。
お店の方が自分で更新するなら、WordPress版をおすすめします。
