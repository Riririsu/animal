# あにまるカフェ Oasis — Webサイト

Claude Design の「Oasis デザイン v2 全ページ」を、HTML / CSS / JavaScript に分けて実装したものです。
デザインは1枚のカンバス（PC 1280px とスマホ 390px の並記）でしたが、実際のサイトとして
**1つのHTMLがPCでもスマホでも見られるレスポンシブ構成**にしています。

---

## 公開URL

**https://riririsu.github.io/animal/**

このブランチに push すると GitHub Actions が自動でサイトを公開します。
公開されるのは HTML・CSS・JS・画像だけで、`README.md` と `docs/` は含まれません
（リポジトリ上には残ります）。

公開済みです（初回デプロイ 2026-08-17、GitHub 側のデプロイ結果は success）。

以降は push するだけで自動更新されます。
公開の履歴は **Actions → Deploy to GitHub Pages** から確認できます。

ワークフローが Pages を自動で有効にする設定
（`.github/workflows/pages.yml` の `enablement: true`）にしてあるので、
Settings 画面を触らなくても push だけで公開されます。

**非公開に戻したいとき**は、次の2つを両方やってください。

1. `Settings → Pages → Build and deployment → Source` を無効にする
2. `.github/workflows/pages.yml` の `enablement: true` を `false` に戻す

2 をやらないと、次に push したときにまた自動で公開されてしまいます。

### 独自ドメインにする場合

1. `Settings → Pages → Custom domain` にドメインを入力
2. サイト側は、全ページの `canonical` / `og:url` / `og:image` と
   `robots.txt` / `sitemap.xml` / `index.html` の構造化データにある
   `https://riririsu.github.io/animal/` を新しいドメインに置き換え

```bash
sed -i 's|https://riririsu.github.io/animal/|https://example.com/|g' *.html robots.txt sitemap.xml
```

## レスポンシブの作り

**文字サイズ・余白・写真の大きさは、画面幅に比例して連続的に変化します。**
特定の幅で急にガクッと変わることがありません（CSS の `clamp()` を使用）。

- 基準：**スマホ = iPhone SE（375px）** ／ **PC = 1280px**（デザイン原寸）
- 375px より狭い端末では 375px のときの大きさを維持、1280px より広ければ 1280px のときの大きさを維持

実測値（トップページ）：

| 画面幅 | ヒーロー見出し | 見出し h2 | 本文 | 左右余白 |
|---|---|---|---|---|
| 375px（iPhone SE） | 31.0px | 23.0px | 15.0px | 18px |
| 600px | 36.2px | 26.3px | 15.3px | 28px |
| 768px（タブレット） | 40.1px | 28.7px | 15.4px | 36px |
| 1024px | 46.1px | 32.4px | 15.7px | 48px |
| 1280px（PC） | 52.0px | 36.0px | 16.0px | 60px |

レイアウトそのものを組み替える区切りは、必要な2か所だけに絞っています。

- **1024px 以下** … ナビをハンバーガーメニューに、横並びを縦積みに
- **700px 以下** … 手順カードを「番号＋文章」の横並びに、画面下部に固定CTAを表示、
  本文に重なる装飾を非表示に

320px（iPhone SE 第1世代）でも崩れないよう保険を入れてあります。

## 付けたアニメーション

### 画面を開いたとき
| 場所 | 動き |
|---|---|
| ヒーローの写真 | 2.4秒かけてゆっくり引く（奥行きを出す） |
| 見出し → 本文 → ボタン → 駐車場バッジ | 0.15秒ずつ間を空けて、下からふわっと順番に登場 |
| 下層ページの見出し | パンくず → ラベル → タイトル → 説明文の順に登場 |

### スクロールしたとき
| 場所 | 動き |
|---|---|
| 各セクション | 画面に入ったところで下からふわっと表示（`IntersectionObserver`） |
| 左右に分かれたブロック | 文章は左から、写真は右からスライドイン |
| カードの列（どうぶつ・手順・お知らせ） | 0.09秒ずつずらして順番に表示 |
| どうぶつの丸写真 | ぷくっとふくらんで登場 |
| ヘッダー | 24px スクロールすると縮んで、半透明＋影が付く |

### 常に動いているもの（ゆっくり・控えめ）
| 場所 | 動き |
|---|---|
| 葉のモチーフ | 9秒周期で風に揺れる |
| 足あと | 6秒周期でふわふわ浮く |
| 水彩のにじみ | 16秒周期でゆっくり呼吸する |
| 有機的なかたちの写真枠 | 18〜22秒かけて少しずつ形が変わる |
| 「本日 営業中」のランプ | 2.4秒周期でぽわんと光る（営業時間外は消灯） |

常時動くもの（葉・足あと・にじみ・形の変化・ランプ）は、**ページの表示が
落ち着いてから動き始めます**。最初から動かすと「描画が終わらない」と判定され、
表示速度の評価が下がるためです。見た目の印象は変わりません。

### さわったとき
| 場所 | 動き |
|---|---|
| ボタン | 3px 浮き上がる＋影が濃くなる＋光がさっと流れる＋矢印が右に進む |
| ナビゲーション | 下線が左から伸びる |
| ロゴ | 少し傾いて拡大 |
| カード | 8px 浮き上がる＋写真が 1.06 倍に寄る＋名前が緑になる |
| 手順カード | 浮き上がる＋番号が回転して水色に変わる |
| どうぶつの丸写真 | 浮き上がって拡大＋縁の色が変わる |
| どうぶつ個別ページのサムネイル | 3px 浮き上がる／押すと上の大きな写真がふわっと入れ替わる |

| お知らせの行 | 背景が付いて右にずれる |
| スマホメニュー | 右からスライドイン＋リンクが順番に登場、ハンバーガーが×に変形 |

### 営業状況の自動表示

トップページの「本日 営業中 11:00 – 19:00」は、**曜日と時刻から自動で切り替わります**。

| 状況 | 表示 |
|---|---|
| 営業時間内 | 本日 営業中 11:00 – 19:00（緑・ランプ点灯） |
| 開店前 | 本日 11:00 開店 |
| 閉店後 | 本日の営業は終了しました |
| 定休日 | 本日 定休日（火曜） |
| 臨時休業 | 本日 臨時休業 |

営業時間・定休日・臨時休業は `js/main.js` の先頭付近にある `HOURS` を直すだけです。

```js
var HOURS = {
  open: '11:00',
  close: '19:00',
  closedDays: [2],        // 0=日 1=月 2=火 …
  closedDayLabel: '火曜',
  holidays: ['2026-08-20'] // 臨時休業日をここに追加
};
```

### 配慮していること
- **`prefers-reduced-motion`（動きを減らす設定）に対応**しています。
  OS側で「視差効果を減らす」を有効にしている方には、すべての動きを止めて内容だけを表示します。
- **JavaScriptが動かない環境でも本文は表示されます**（`.no-js` による保険）。
- キーボード操作のフォーカス枠、スキップリンク、`aria-current` / `aria-expanded` などを入れています。

## 差し替えが必要な箇所

デザインが仮の状態だった部分は、そのまま**プレースホルダ**として残しています。

### 1. 電話番号
全ページの `tel:0000000000` と、表示上の `000-000-0000` を実際の番号に置き換えてください。

```bash
# 一括置換の例（0995-XX-XXXX の部分を実際の番号に）
sed -i 's/0000000000/0995XXXXXX/g; s/000-000-0000/0995-XX-XXXX/g' *.html
```

### 2. Instagram のリンク
`href="#instagram"` が21か所あります。実際のプロフィールURLに置き換えてください。

```bash
sed -i 's|href="#instagram"|href="https://www.instagram.com/XXXX/" target="_blank" rel="noopener"|g' *.html
```

### 3. 住所
`鹿児島県霧島市国分—————` が仮のままです。実際の住所に置き換えてください。

### 4. 写真

いただいた **22種・67枚の写真は入れ込み済み**です。まだ写真がないのは次の13か所で、
色のついた四角のまま残しています（`docs/photo-guide.md` に一覧があります）。

| ページ | 足りていない写真 |
|---|---|
| トップ | 来店の流れ3枚／ドリンク・ケーキ2枚／Googleマップ |
| 店舗紹介 | 店内の様子／外観 |
| メニュー | ドリンク・ケーキ |
| 生体販売 | 説明の様子 |
| アクセス | Googleマップ |
| お知らせ | 「臨時休業のお知らせ」のカード |

写真をお送りいただければ同じように入れ込みます。ご自身で入れる場合は、
プレースホルダの1行をまるごと `<img>` に置き換えてください。

```html
<!-- 今の状態 -->
<div class="photo photo--organic photo-cluster__a">実物写真：店内の様子</div>

<!-- 写真に差し替えるとき（class はそのまま残す） -->
<img class="photo photo--organic photo-cluster__a" src="images/shop.jpg"
     width="800" height="576" loading="lazy" decoding="async" alt="店内の様子">
```

**class を残したまま `<img>` に置き換えるだけで、枠の形どおりに切り抜かれます。**
`object-fit: cover` などの追加指定は不要です（CSS 側で対応済み）。

### 5. 第二駐車場の案内図（要確認）

`images/parking-map.svg` は、**いただいた案内図の画像をもとに作り直したもの**です。
画像ファイルそのものを受け取れなかったため、見た目を参考に描き起こしています。

- **道路の形・位置関係は目視で写したもの**です。実物とずれていないかご確認ください
- 書体が元の画像と異なります（丸ゴシック → Zen Kaku Gothic New）
- SVG のため、拡大しても文字がぼやけません。ファイルサイズは 5KB です
- 文字や色は `images/parking-map.svg` をテキストエディタで直接編集できます

掲載箇所は2か所で、大きさを変えています。

| ページ | 表示サイズ | 備考 |
|---|---|---|
| アクセス | 420×702px | 原寸に近い大きさ |
| トップ | 280×468px | 押すとアクセスページへ移動 |

トップを小さくしているのは、原寸で置くと囲みが縦に伸びすぎて
左の Google マップ（430px）と釣り合わなくなるためです。

元の画像をそのまま使いたい場合は、`images/` に置いて
`index.html` と `access.html` の `parking-map.svg` を差し替えてください。

### 6. Googleマップ
`index.html` と `access.html` の「Googleマップ」と書かれた `<div>` を、
Googleマップの埋め込みコード（`<iframe>`）に置き換えてください。

### 7. 掲載内容
**どうぶつ21種は、いただいた写真と店内POPカードの記載に合わせて実データにしています。**
メニュー・お知らせの各項目はデザイン通りのサンプルなので、実際の内容に差し替えてください。
`news.html` のページ送り（1・2・3・次へ）も、記事が増えたら実際のリンク先に変えてください。

### 8. 「お迎えのご相談」を出す／出さない

どうぶつ個別ページ（`animal-*.html`）の下のほうにある
**「お迎えのご相談」の枠は、1ページごとに出し分けられます。**

ファイルの上のほうにある次の1行を探して、`on` を `off` に書き換えるだけです。

```html
<main id="main" data-adopt="on">      ← 出す
<main id="main" data-adopt="off">     ← 出さない
```

お迎えの取り扱いがない子（ゾウガメなど）は `off` にしてください。
戻したいときは `on` に書き換えれば戻ります。

**22ページまとめて消したいとき**

```bash
sed -i 's/data-adopt="on"/data-adopt="off"/' animal-*.html
```

**まとめて出したいとき**

```bash
sed -i 's/data-adopt="off"/data-adopt="on"/' animal-*.html
```

**一部だけ消したいとき**（例：ゾウガメ2種とミーアキャット）

```bash
sed -i 's/data-adopt="on"/data-adopt="off"/' \
  animal-aldabra.html animal-sulcata.html animal-meerkat.html
```

現在は**22ページすべて `on`（表示する）**にしてあります。

### 9. 構造化データ（`index.html`）
検索結果に営業時間や地図を出すための `application/ld+json` を入れています。
**電話番号・住所・Instagram の URL が仮のままなので、必ず実際の値に書き換えてください。**
仮の値のまま公開すると、検索エンジンに誤った店舗情報が伝わります。

## デザインからの補足・変更点

元データをそのまま使えなかった箇所と、その対応です。

1. **装飾モチーフが未定義だった**
   デザインデータでは葉（`#v2-sprig`）と足あと（`#v2-paw`）が `<use>` で参照されているものの、
   参照先の `<defs>` が空で、ブラウザで開いても何も表示されない状態でした。
   デザインの意図（葉・足あとを全体に散らす）に沿って、SVGを新たに作成しています。

2. **SVGの属性名が壊れていた**
   デザインツールの書き出し都合で `viewBox` が `sc-camel-view-box`、
   `preserveAspectRatio` が `sc-camel-preserve-aspect-ratio` という無効な名前になっていました。
   正しい属性名に直しています。

3. **フォントの読み込み方**
   デザインデータにはWebフォントが975ファイル分（約27MB）埋め込まれていました。
   実サイトでは Google Fonts から読み込む形にしています（Shippori Mincho / Zen Kaku Gothic New）。
   ページの表示速度を優先して、必要な太さだけを指定しています。

4. **スマホでの組み替え**
   デザインのスマホ版に合わせて、以下はレイアウトを変えています。
   - 来店の流れ・ふれあいの流れ：写真を省いて「番号＋文章」の横並びに（縦の長さを抑えるため）
   - ナビゲーション：1024px以下でハンバーガーメニューに
   - 画面下部に「電話 / Instagram」の固定ボタンを追加
   - 本文に重なる装飾（足あと・にじみ）は非表示に

5. **絞り込み機能を実装**
   どうぶつ一覧とお知らせの絞り込みチップは、デザインでは見た目だけでしたが、
   実際に動くようにしています（カード側の `data-cat` と突き合わせ）。

## 文字色の読みやすさ（調整済み）

デザインの指定色のうち6色が、小さな文字の読みやすさの基準
（WCAG AA・コントラスト比 4.5:1）を下回っていたため、**文字に使う色だけ**を調整しました。
**葉・足あと・水彩のにじみといった装飾の色は、デザイン通りのままです。**

| 用途 | 変更前 | 変更後 | コントラスト比 |
|---|---|---|---|
| 補助テキスト（注釈・日付・パンくず） | `#8D8570` | `#736D5C` | 3.2 → 4.5:1 |
| 緑のラベル（ANIMALS / ACCESS 等） | `#8FA86B` | `#607444` | 2.3 → 4.5:1 |
| 金のラベル（RULES / EXPERIENCE） | `#C9A46A` | `#896732` | 2.0 → 4.5:1 |
| タグの文字（餌やり体験・休業） | `#A9762A` | `#8E6323` | 3.4 → 4.6:1 |
| 深緑地のラベル | `#A9C79E` | `#B6CFAC` | 4.1 → 4.5:1 |
| 深緑地の法令表記 | `#93AD86` | `#BDCDB5` | 3.1 → 4.5:1 |

色相と彩度は保ったまま、明度だけを必要最小限だけ動かしています。
全9ページをブラウザで実測し、本文・見出し・リンクを含めて基準未達がないことを確認済みです。

デザイン通りの色に戻したい場合は、`css/style.css` の
「色（文字用）」の6行を元の値に書き換えてください。

※「推奨事項」は、この作業環境では Google Fonts への通信がブロックされる関係で
96 と出ます。フォントの読み込み行を外して計測すると 100 になることを確認済みで、
公開後の実環境では 100 になります。

モバイルの性能が 100 でないのは、どうぶつ個別ページだけです（95〜99）。
大きな写真が1枚入るぶん、低速回線での表示完了が数百ミリ秒遅くなるためで、
基準（90以上）は全ページで満たしています。

写真を入れるにあたって行った速度対策：

- 写真はすべて **WebP** に変換（JPEGより3〜4割軽い）
- 表示サイズごとに書き出しを分けた
  （一覧カード 720px／個別ページ 1100px・スマホ用 700px／サムネイル 260px／丸 360px）
- 個別ページのメイン写真は `srcset` で、スマホでは軽い方を読み込む
- 画面外の写真は `loading="lazy"` で後回し
- すべての `<img>` に `width` / `height` を入れ、読み込み前に場所を確保
  （読み込み中に文字が飛ぶ「ガタつき」を防ぐ）

**営業状況の自動切り替え（6パターン）**

開店前／営業中／閉店後／深夜／定休日／日曜 のすべてで期待どおりの表示を確認

## WordPress 版について

`wordpress/animal-cafe-oasis/` に、**この静的サイトを WordPress テーマにしたもの**が入っています。
静的サイトはそのまま残してあるので、どちらも使えます。

| | 静的サイト（このフォルダの直下） | WordPress 版（`wordpress/animal-cafe-oasis/`） |
|---|---|---|
| 更新のしかた | HTMLファイルを直接編集 | **管理画面から** |
| 写真の差し替え | `images/` に上書き | **管理画面でアップロード**（切り抜きは自動） |
| どうぶつの追加 | HTMLを書き足す | **「どうぶつ」→ 新規追加** |
| 「お迎えのご相談」 | `data-adopt="on"/"off"` を書き換え | **チェックボックス**（1件ずつ／まとめて／サイト全体） |
| 営業時間の変更 | `js/main.js` を編集 | **設定画面**（「本日 営業中」の自動表示も連動） |
| 公開先 | GitHub Pages | レンタルサーバーなど |

### できること

- **どうぶつ**：カスタム投稿タイプ。カテゴリで一覧の絞り込みが動きます
- **写真**：メイン写真＝アイキャッチ画像。サブ写真とPOPカードはメディアから選択。
  1枚アップロードすれば、カード用・丸用・サムネイル用に**自動で切り抜かれます**
- **お迎えのご相談**：どうぶつごとのチェックボックス。一覧からまとめて切り替えも可能。
  サイト全体のオン・オフも設定画面にあります
- **サイト共通設定**：電話番号・住所・Instagram・営業時間・定休日・臨時休業日・
  Googleマップ・入場料・動物取扱業の表記を1か所で管理
- **初期データの取り込み**：ボタン1つで、どうぶつ21種（写真67枚＋POPカード22枚）と
  固定ページ6枚、メニュー3種をまとめて登録

### 導入手順

`wordpress/readme-oasis.md` に、画面の操作手順を書いています。
おおまかには次の3ステップです。

1. 外観 → テーマ → 新規追加 → テーマのアップロードで zip を入れて有効化
2. 設定 → Oasis サイト設定 →「初期データを取り込む」
3. 同じ画面で電話番号・住所・Instagram などを実際の値に

### 配布用の zip を作り直すには

```bash
cd wordpress && zip -r animal-cafe-oasis.zip animal-cafe-oasis
```
