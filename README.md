# あにまるカフェ Oasis — Webサイト

Claude Design の「Oasis デザイン v2 全ページ」を、HTML / CSS / JavaScript に分けて実装したものです。
デザインは1枚のカンバス（PC 1280px とスマホ 390px の並記）でしたが、実際のサイトとして
**1つのHTMLがPCでもスマホでも見られるレスポンシブ構成**にしています。

---

## ファイル構成

```
.
├── index.html      トップページ
├── about.html      店舗紹介・コンセプト／スタッフ紹介／店舗情報
├── animals.html    どうぶつ紹介（一覧・絞り込みつき）
├── animal.html     どうぶつ個別プロフィール（POPカード掲載）
├── menu.html       メニュー・料金
├── rules.html      ご利用ルール・注意事項
├── access.html     アクセス・駐車場
├── sales.html      生体販売・お迎えのご相談
├── news.html       お知らせ・ブログ（絞り込みつき）
│
├── css/
│   ├── style.css       配色・文字・レイアウト・部品（見た目の土台）
│   └── animations.css  アニメーションのみをまとめたファイル
│
├── js/
│   └── main.js     スクロール連動・スマホメニュー・絞り込み
│
└── images/
    └── logo.jpg    ロゴ
```

CSSを2つに分けているのは、**「見た目」と「動き」を別々に調整できるようにする**ためです。
アニメーションをまとめて止めたい・差し替えたいときは `animations.css` だけを見れば済みます。

サーバー不要で、`index.html` をブラウザで開けばそのまま動きます。

## 付けたアニメーション

### 画面を開いたとき
| 場所 | 動き |
|---|---|
| ヒーローの背景 | 14秒かけてゆっくり引く（奥行きを出す） |
| 見出し → 本文 → ボタン → 駐車場バッジ | 0.15秒ずつ間を空けて、下からふわっと順番に登場 |
| 下層ページの見出し | パンくず → ラベル → タイトル → 説明文の順に登場 |

### スクロールしたとき
| 場所 | 動き |
|---|---|
| 各セクション | 画面に入ったところで下からふわっと表示（`IntersectionObserver`） |
| 左右に分かれたブロック | 文章は左から、写真は右からスライドイン |
| カードの列（どうぶつ・手順・お知らせ） | 0.09秒ずつずらして順番に表示 |
| どうぶつの丸写真 | ぷくっとふくらんで登場 |
| ヘッダー | 24px スクロールすると縮んで、半透明＋影が付く |

### 常に動いているもの（ゆっくり・控えめ）
| 場所 | 動き |
|---|---|
| 葉のモチーフ | 9秒周期で風に揺れる |
| 足あと | 6秒周期でふわふわ浮く |
| 水彩のにじみ | 16秒周期でゆっくり呼吸する |
| 有機的なかたちの写真枠 | 18〜22秒かけて少しずつ形が変わる |
| 「本日 営業中」のランプ | 2.4秒周期でぽわんと光る |

### さわったとき
| 場所 | 動き |
|---|---|
| ボタン | 3px 浮き上がる＋影が濃くなる＋光がさっと流れる＋矢印が右に進む |
| ナビゲーション | 下線が左から伸びる |
| ロゴ | 少し傾いて拡大 |
| カード | 8px 浮き上がる＋写真が 1.06 倍に寄る＋名前が緑になる |
| 手順カード | 浮き上がる＋番号が回転して水色に変わる |
| どうぶつの丸写真 | 浮き上がって拡大＋縁の色が変わる |
| お知らせの行 | 背景が付いて右にずれる |
| スマホメニュー | 右からスライドイン＋リンクが順番に登場、ハンバーガーが×に変形 |

### 配慮していること
- **`prefers-reduced-motion`（動きを減らす設定）に対応**しています。
  OS側で「視差効果を減らす」を有効にしている方には、すべての動きを止めて内容だけを表示します。
- **JavaScriptが動かない環境でも本文は表示されます**（`.no-js` による保険）。
- キーボード操作のフォーカス枠、スキップリンク、`aria-current` / `aria-expanded` などを入れています。

## 差し替えが必要な箇所

デザインが仮の状態だった部分は、そのまま**プレースホルダ**として残しています。

### 1. 電話番号
全ページの `tel:0000000000` と、表示上の `000-000-0000` を実際の番号に置き換えてください。

```bash
# 一括置換の例（0995-XX-XXXX の部分を実際の番号に）
sed -i 's/0000000000/0995XXXXXX/g; s/000-000-0000/0995-XX-XXXX/g' *.html
```

### 2. Instagram のリンク
`href="#instagram"` が21か所あります。実際のプロフィールURLに置き換えてください。

```bash
sed -i 's|href="#instagram"|href="https://www.instagram.com/XXXX/" target="_blank" rel="noopener"|g' *.html
```

### 3. 住所
`鹿児島県霧島市国分—————` が仮のままです。実際の住所に置き換えてください。

### 4. 写真
デザイン段階では写真がすべて仮だったため、**グラデーションの四角＋説明文**で置いています。

```html
<!-- 今の状態 -->
<div class="photo photo--organic photo-cluster__a">実物写真：店内の様子</div>

<!-- 写真に差し替えるとき -->
<img class="photo photo--organic photo-cluster__a" src="images/shop.jpg" alt="店内の様子">
```

`.photo--organic` などの丸みのある形はそのまま使えます。`<img>` にする場合は
`object-fit: cover;` を足すときれいに収まります。

### 5. Googleマップ
`index.html` と `access.html` の「Googleマップ」と書かれた `<div>` を、
Googleマップの埋め込みコード（`<iframe>`）に置き換えてください。

### 6. 掲載内容
どうぶつ・メニュー・お知らせの各項目はデザイン通りのサンプルです。実際の内容に差し替えてください。
`news.html` のページ送り（1・2・3・次へ）も、記事が増えたら実際のリンク先に変えてください。

### 7. SNSシェア用の画像URL（`og:image`）
全ページの `<meta property="og:image" content="images/logo.jpg">` は相対パスです。
**公開ドメインが決まったら絶対URLに書き換えてください。** 相対パスのままだと、
LINE や X でシェアしたときにサムネイルが表示されません。

```bash
sed -i 's|content="images/logo.jpg"|content="https://example.com/images/logo.jpg"|g' *.html
```

### 8. 構造化データ（`index.html`）
検索結果に営業時間や地図を出すための `application/ld+json` を入れています。
**電話番号・住所・Instagram の URL が仮のままなので、必ず実際の値に書き換えてください。**
仮の値のまま公開すると、検索エンジンに誤った店舗情報が伝わります。

## デザインからの補足・変更点

元データをそのまま使えなかった箇所と、その対応です。

1. **装飾モチーフが未定義だった**
   デザインデータでは葉（`#v2-sprig`）と足あと（`#v2-paw`）が `<use>` で参照されているものの、
   参照先の `<defs>` が空で、ブラウザで開いても何も表示されない状態でした。
   デザインの意図（葉・足あとを全体に散らす）に沿って、SVGを新たに作成しています。

2. **SVGの属性名が壊れていた**
   デザインツールの書き出し都合で `viewBox` が `sc-camel-view-box`、
   `preserveAspectRatio` が `sc-camel-preserve-aspect-ratio` という無効な名前になっていました。
   正しい属性名に直しています。

3. **フォントの読み込み方**
   デザインデータにはWebフォントが975ファイル分（約27MB）埋め込まれていました。
   実サイトでは Google Fonts から読み込む形にしています（Shippori Mincho / Zen Kaku Gothic New）。
   ページの表示速度を優先して、必要な太さだけを指定しています。

4. **スマホでの組み替え**
   デザインのスマホ版に合わせて、以下はレイアウトを変えています。
   - 来店の流れ・ふれあいの流れ：写真を省いて「番号＋文章」の横並びに（縦の長さを抑えるため）
   - ナビゲーション：1024px以下でハンバーガーメニューに
   - 画面下部に「電話 / Instagram」の固定ボタンを追加
   - 本文に重なる装飾（足あと・にじみ）は非表示に

5. **絞り込み機能を実装**
   どうぶつ一覧とお知らせの絞り込みチップは、デザインでは見た目だけでしたが、
   実際に動くようにしています（カード側の `data-cat` と突き合わせ）。

## 未対応（ご判断待ち）：文字色のコントラスト

デザインの指定色のうち6色が、**小さな文字の読みやすさの基準（WCAG AA・4.5:1）を下回っています**。
実測値は次の通りです。

| 用途 | 色 | 背景 | 実測 | 判定 |
|---|---|---|---|---|
| 補助テキスト（注釈・日付・パンくず） | `#8D8570` | クリーム | 3.43:1 | 基準未満 |
| 緑のラベル（ANIMALS / ACCESS 等） | `#8FA86B` | クリーム | 2.46:1 | 基準未満 |
| 金のラベル（RULES / EXPERIENCE） | `#C9A46A` | 白 | 2.33:1 | 基準未満 |
| 緑地の上のラベル | `#A9C79E` | 深緑 | 4.09:1 | わずかに未満 |
| 緑地の上の法令表記 | `#93AD86` | 深緑 | 3.08:1 | 基準未満 |
| タグの文字（餌やり体験・休業） | `#A9762A` | 薄い金 | 3.40:1 | 基準未満 |

**ブランドカラーの変更にあたるため、こちらの判断では変えていません。**
濃くすると読みやすくなる一方、デザインの持つ「やわらかい印象」は少し弱まります。
ご希望があれば調整します（基準を満たす色は算出済みです）。

なお、本文（`#57503F`／7.48:1）・見出し（`#25412A`／10.51:1）・
リンク（`#2E5E3A`／7.07:1）は基準を満たしています。

## 動作確認済み

Chromium（Playwright）で全9ページ × PC 1440px / スマホ 390px を確認しています。

- 全ページでJavaScriptエラーなし・読み込み失敗なし
- 横スクロールの発生なし
- スクロール連動の表示がすべて発火する
- 絞り込み・スマホメニュー・ヘッダー縮小が動作する
- 「動きを減らす」設定でも、JavaScript無効でも、本文がすべて表示される
