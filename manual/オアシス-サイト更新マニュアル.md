# あにまるカフェ Oasis｜サイト更新マニュアル

お店のホームページを、**ご自身で更新するための説明書**です。
パソコンが苦手な方でも進められるように、画面の場所から順番に書いています。

> このマニュアルはサイトのプログラムとは別のファイルです。
> 印刷して手元に置いていただいても構いません。

## 1. まずログインする

### ログイン画面を開く

ブラウザのアドレス欄に、次を入力します。

```
（お店のホームページのURL）/wp-admin/
```

例：`https://animal-cafe-oasis.com/wp-admin/`

ユーザー名とパスワードを入れて「**ログイン**」。

> **ブックマークしておくと毎回楽です。**
> 「ログイン状態を保存する」にチェックを入れておくと、しばらくログインしたままになります。

### 画面の見かた

ログインすると、左側にメニューが縦に並びます。**この左メニューから目的の場所へ行きます。**

| 左メニュー | 何をする場所か |
|---|---|
| **どうぶつ** | どうぶつの写真・説明を変える |
| **投稿** | お知らせ・ブログを書く |
| **メディア** | アップロードした写真の置き場 |
| **固定ページ** | 店舗紹介・メニューなどのページ |
| **設定** | 電話番号・営業時間・写真の差し替え |

### 更新した内容を見るには

画面いちばん上の左にある**家のマーク（サイト名）**にマウスを乗せて、
「**サイトを表示**」をクリックします。

## 2. 写真を差し替える

サイトの写真は、**置き場所によって変える画面が違います。**

| どの写真か | どこで変えるか |
|---|---|
| どうぶつの写真 | **どうぶつ** → 名前をクリック |
| お知らせの写真 | **投稿** → 記事の「アイキャッチ画像」 |
| **それ以外すべて** | **設定 → Oasis 写真の差し替え** |

### 2-1. トップページや店内の写真を変える

**設定 → Oasis 写真の差し替え**

1つの画面に、差し替えできる写真がすべて並んでいます。

**手順**

1. 変えたい写真の下の「**写真を選ぶ**」を押す
2. 「**ファイルをアップロード**」タブ → 「**ファイルを選択**」→ パソコンの写真を選ぶ
   （すでにアップ済みなら「メディアライブラリ」タブから選べます）
3. 右下の「**この写真を使う**」を押す
4. 画面いちばん下の「**写真を保存**」を押す ← **忘れやすいので注意**

**差し替えできる写真の一覧**

| グループ | 写真 |
|---|---|
| トップページ | いちばん上の大きな写真／店舗紹介の3枚／来店の流れ①②③／第二駐車場の案内図 |
| 店舗紹介ページ | 店内の様子／お店の外観／スタッフ3名 |
| メニュー・生体販売 | トップのドリンク2枚／メニューページの写真／ご説明の様子 |
| お知らせ | トップに出す「臨時休業」の丸写真 |

**写真をやめたいとき**は、写真の右上の「**×**」を押してから「写真を保存」。
色のついた四角に戻ります。

### 2-2. 写真を用意するときのコツ

- **スマホで撮った写真をそのまま**使えます。サイズ調整は自動です
- **被写体は中央に**。切り抜きは中央が基準です
- **明るい場所で**撮ると綺麗に見えます
- 「いちばん上の大きな写真」だけは、**被写体が右寄り**の写真がおすすめです
  （左半分に文字が重なるため）
- **お客様が写っている写真は、公開の許可を取ってから**使ってください

## 3. どうぶつを追加・変更する

### 3-1. すでにいる子の内容を変える

**どうぶつ** をクリック → 変えたい子の**名前をクリック**

編集画面には次の欄があります。

| 欄 | 内容 |
|---|---|
| タイトル（いちばん上） | どうぶつの名前 |
| **写真** | サブ写真・店内POPカード |
| 右上「**メイン写真**」 | 一覧・個別ページの大きな写真に使われます |
| 右「**カテゴリ**」 | 一覧の絞り込みに使われます |
| 右「**お迎えのご相談**」 | 下の枠を出すかどうか |
| 右「**順序**」 | 一覧に並ぶ順番（数字が小さいほど前） |
| **どうぶつのデータ** | 原産地・大きさ・寿命・食べ物・特徴・豆知識 |

直したら、右上の青い「**更新**」ボタンを押します。

**サブ写真の並べ替え**
「写真」の欄の小さい写真は、**ドラッグで順番を入れ替えられます。**
この順番が、ページのサムネイルの並び順になります。

### 3-2. 新しい子を追加する

**どうぶつ → 新規追加**

1. いちばん上に**名前**を入れる（例：`ハムスター`）
2. 右の「**カテゴリ**」で当てはまるものを選ぶ
3. 右の「**メイン写真**」で、いちばん見せたい写真を選ぶ
4. 「**写真**」の欄で、サブ写真と店内POPカードを選ぶ
5. 「**どうぶつのデータ**」に、店内POPカードの内容を書き写す
6. 右上の「**公開**」を押す

> **カテゴリを選び忘れる**と、一覧の絞り込みに出てきません。必ず選んでください。

### 3-3. 一時的に隠したい / 消したい

**一時的に隠す**（お迎え先が決まった、体調が悪いなど）
編集画面の右上「**公開状態：公開**」の横の「編集」→「**下書き**」→「OK」→「更新」

**完全に消す**
どうぶつの一覧で、名前にマウスを乗せて「**ゴミ箱へ移動**」

> ゴミ箱に入れても30日間は元に戻せます。

## 4. 「お迎えのご相談」を出す・出さない

どうぶつの個別ページの下のほうに出る、**電話・Instagramのご案内の枠**です。
お迎えの取り扱いがない子には、出さないようにできます。

### 1匹ずつ変える

**どうぶつ** → 名前をクリック → 右側の「**お迎えのご相談**」

- チェックが入っている → 出る
- チェックを外す → 出ない

「更新」を押して保存します。

### まとめて変える

1. **どうぶつ** の一覧を開く
2. 変えたい子の**左側の四角にチェック**を入れる（複数OK）
3. 上の「**一括操作**」から
   「お迎えのご相談を『出す』にする」または「『出さない』にする」を選ぶ
4. 「**適用**」を押す

### サイト全体で消す

**設定 → Oasis サイト設定 → 表示の切り替え**
→「**お迎えのご相談を使う**」のチェックを外す → 変更を保存

> どの子が今どうなっているかは、**どうぶつの一覧の「お迎え」の列**で見られます。
> 「● 出す」「— 出さない」と表示されます。

## 5. お知らせを書く

### 5-1. 新しい記事を書く

**投稿 → 新規追加**

1. いちばん上に**タイトル**（例：`8月20日は臨時休業します`）
2. その下の広い場所に**本文**を書く
3. 右の「**カテゴリー**」から選ぶ
   - **入荷** … 新しい仲間が来たとき
   - **休業** … 臨時休業のお知らせ
   - **店内の様子** … その他のお知らせ
4. 右の「**アイキャッチ画像**」で写真を選ぶ（一覧のカードに出る写真です）
5. 右上の「**公開**」

書いた記事は、**トップページとお知らせページに自動で出ます。**

### 5-2. 日付を指定して公開する

「公開」ボタンの上にある「**今すぐ**」をクリックすると、日時を指定できます。
指定した日時になると自動で公開されます。

### 5-3. 書いたものを直す・消す

**投稿** の一覧から、タイトルをクリックして直します。
消すときは、タイトルにマウスを乗せて「**ゴミ箱へ移動**」。

## 6. 営業時間・臨時休業を変える

**設定 → Oasis サイト設定 → 営業時間**

| 項目 | 説明 |
|---|---|
| 開店時刻 / 閉店時刻 | 例：`11:00` / `19:00` |
| 定休日 | 曜日にチェック |
| **臨時休業日** | `2026-08-20` の形で、**1行に1つ** |
| 入場料の表記 | 例：`1,000円（2ドリンク付）` |
| トップに出す料金の一覧 | `項目名|価格` を1行に1つ |

最後に「**変更を保存**」。

### 「本日 営業中」の表示について

トップページの「**本日 営業中 11:00 – 19:00**」は、
**ここの設定をもとに、曜日と時刻から自動で切り替わります。**

| 状況 | 表示 |
|---|---|
| 営業時間内 | 本日 営業中 11:00 – 19:00 |
| 開店前 | 本日 11:00 開店 |
| 閉店後 | 本日の営業は終了しました |
| 定休日 | 本日 定休日（火曜） |
| 臨時休業日 | 本日 臨時休業 |

**臨時休業を入れたら、その日を過ぎたら消しておく**と分かりやすいです
（残っていても表示に問題はありません）。

## 7. 電話番号・住所などを変える

**設定 → Oasis サイト設定 → お店の情報**

ここを直すと、**サイト全部の表示がまとめて変わります。**
ページを1枚ずつ直す必要はありません。

| 項目 | 注意 |
|---|---|
| 電話番号（表示用） | ハイフンあり。例：`0995-XX-XXXX` |
| **電話番号（発信用）** | **ハイフンなし**。例：`0995XXXXXX` |
| 住所 | フッターとアクセスページに出ます |
| Instagram の URL | 空にすると、Instagramのボタンが消えます |
| 第一種動物取扱業 | フッターの小さい文字 |
| Googleマップの埋め込みコード | 下記参照 |

### Googleマップの入れかた

1. Googleマップでお店を開く
2. 「**共有**」→「**地図を埋め込む**」→「**HTMLをコピー**」
3. 「Googleマップの埋め込みコード」の欄に**貼り付け**
4. 「変更を保存」

トップページとアクセスページの地図が、まとめて入れ替わります。

## 8. ページの文章を直す

**固定ページ** をクリックすると、ページの一覧が出ます。

| ページ | 内容 |
|---|---|
| 店舗紹介・コンセプト | お店の説明・スタッフ紹介・店舗情報 |
| メニュー・料金 | 価格表 |
| ご利用ルール | お願いごと |
| アクセス・駐車場 | 地図・駐車場の案内 |
| 生体販売・お迎えのご相談 | お迎えまでの流れ |

直したいページの**タイトルをクリック**すると編集画面になります。

### ⚠ 文章を直すときの大事な注意

これらのページの中身は「**HTML**」という形で入っています。

- **文字の部分だけを直してください**
- `<` `>` で囲まれた部分は**さわらないでください**
- 直したら右上の「**更新**」

**例：料金を直す場合**

```html
<div class="row"><span>入場料</span><span class="row__value">1,000円</span></div>
                        ↑ここと                        ↑ここだけ直す
```

> **不安なときは、直す前に本文をぜんぶコピーしてメモ帳に貼っておいてください。**
> おかしくなったら貼り戻せます。

## 9. 困ったときは

| 症状 | どうするか |
|---|---|
| 変えたのにサイトに出ない | 「更新」「保存」を押したか確認。押していたら、ブラウザで **Ctrl + Shift + R**（Macは Cmd + Shift + R） |
| 写真が古いまま | 上と同じ。それでもダメなら、写真を選び直して保存 |
| 写真の切り抜きがおかしい | 被写体が中央にある写真に変えてみてください |
| ページの見た目が崩れた | 直前に直した文章を元に戻す。分からなければご連絡ください |
| ログインできない | ログイン画面の「**パスワードをお忘れですか？**」から再設定 |
| 画面が真っ白になった | **何も触らずにご連絡ください** |

### 連絡するときに伝えていただきたいこと

1. **どのページ**か（URLをコピーして送ると確実です）
2. **何をしたら**そうなったか
3. **画面の写真**（スマホで撮ったものでOK）

## 10. やってはいけないこと

| やってはいけないこと | 理由 |
|---|---|
| **外観 → テーマ** で別のテーマを有効化する | サイトの見た目が全部なくなります |
| **外観 → テーマファイルエディター** をさわる | 1文字間違えるとサイトが表示されなくなります |
| **プラグイン** を勝手に入れる | サイトが壊れることがあります。入れる前にご相談ください |
| **設定 → パーマリンク** を変える | すべてのページのURLが変わり、Googleの検索結果から消えます |
| 固定ページの `<` `>` の部分を消す | ページの見た目が崩れます |
| **どうぶつ・固定ページを完全に削除**する | 元に戻せなくなります。まずは「下書き」に |

## 覚えておくと便利なこと

- **保存ボタンは必ず押す**。「更新」「変更を保存」「写真を保存」
- **迷ったら何も押さずに閉じる**。保存しなければ変わりません
- **スマホでも管理画面に入れます**。お知らせを書くくらいなら十分です
- **月に1回でもお知らせを書く**と、Googleの検索に出やすくなります
