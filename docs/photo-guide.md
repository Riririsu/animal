# 写真の差し替え対応表

どのファイルの、どの記述を、何に置き換えるかの一覧です。
**プレースホルダの1行をまるごと `<img>` に置き換えるだけ**で、枠の形（丸・有機的なかたち）に
合わせて自動で切り抜かれます。CSS 側は対応済みなので、追加の指定は不要です。

```html
<!-- 置き換え前 -->
<div class="photo photo--organic photo-cluster__a">実物写真：店内の様子</div>

<!-- 置き換え後（class はそのまま残してください） -->
<img class="photo photo--organic photo-cluster__a" src="images/shop.jpg" alt="店内の様子">
```

- **class は必ずそのまま残してください。** 形・大きさ・アニメーションはすべて class に紐づいています。
- `alt` には写真の内容を短く書いてください（読み上げと検索対策に使われます）。
- 推奨サイズは「表示サイズの2倍」です。高解像度画面（iPhone など）で綺麗に見せるためです。
- 画像は `images/` フォルダに入れてください。

## 写真の準備について

- 形式は **JPG / PNG / WebP** のいずれでも構いません。
- 元写真が推奨サイズより大きい場合は、推奨サイズまで縮小してから入れると表示が速くなります。
- 正円・有機的なかたちの枠は**中央を基準に切り抜かれます**。被写体が中央にくる写真を選んでください。
- ヒーロー（トップ最上部）は**左半分に文字が重なります**。被写体が右寄りの写真だと文字が読みやすくなります。

## Googleマップ

`index.html` と `access.html` の「Googleマップ」の枠は、写真ではなく埋め込みコードに置き換えます。

1. Googleマップでお店を開く
2. 「共有」→「地図を埋め込む」
3. 表示された `<iframe ...>` をコピー
4. プレースホルダの1行と差し替え、`<iframe>` に `style="width:100%;height:430px;border:0;border-radius:28px"` を追加

## 入れたあとに確認すること

- 切り抜きで顔や被写体が切れていないか
- ブラウザを狭めて、スマホ幅でも破綻していないか
- お客様が写り込んでいる写真は、公開の許可が取れているか
