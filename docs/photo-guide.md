### 入れ方

プレースホルダの1行をまるごと `<img>` に置き換えるだけです。**class はそのまま残してください。**
形・大きさ・アニメーションはすべて class に紐づいています。

```html
<!-- 置き換え前 -->
<div class="photo photo--organic photo-cluster__a">実物写真：店内の様子</div>

<!-- 置き換え後 -->
<img class="photo photo--organic photo-cluster__a" src="images/shop.jpg"
     width="800" height="576" loading="lazy" decoding="async" alt="店内の様子">
```

- 形式は JPG / PNG / WebP のいずれでも構いません。
- 正円・有機的なかたちの枠は**中央を基準に切り抜かれます**。被写体が中央にくる写真を選んでください。
- お客様が写り込んでいる写真は、公開の許可が取れているかご確認ください。

### Googleマップ

1. Googleマップでお店を開く → 「共有」→「地図を埋め込む」
2. 表示された `<iframe ...>` をコピー
3. プレースホルダの1行と差し替え、`<iframe>` に
   `style="width:100%;height:430px;border:0;border-radius:28px"` を追加

## 3. 写真を差し替えたいとき

同じファイル名で `images/` に上書きするだけで反映されます。
サイズが大きく違うと表示が崩れることがあるので、上の表の推奨サイズに近づけてください。
